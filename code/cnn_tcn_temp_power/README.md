# 灰度 CNN＋TCN＋温度和功率

每窗使用最近 20 张灰度图预测下一帧的稳定、顶丝或熔断。三层 CNN 逐帧编码图像，再交给一路 TCN。单路因果温度 TCN 读取最多 168 个点，功率 MLP 读取对应时段的 84 个功率设定值。三个特征向量拼接后分类。每窗独立，功率和温度历史截止于末张输入图，同层同有效段。

复用公共的第 136 号整墙划分、现有训练层清单和图温标注。在模型比较时，两组训练需要使用相同的数据快照、窗口和未来帧数。长温度输入沿用 ResNet 的真实时间裁剪、训练统计及补齐规则，799.9 只在拟合统计时排除。灰度 CNN 从头训练，使用单路温度结构，和含预训练骨干及长短温度两路的 ResNet 结果一起比较时，体现的是整套网络的差别。

| 文件 | 用途 |
| --- | --- |
| config.py | 调整批量、轮数、输入窗口、权重选择和评估集合。 |
| model.py | 定义图像、温度、功率分支及三分类前向计算。 |
| train.py | 在 IDE 运行训练和逐轮验证，保存最佳权重和报告。 |
| evaluate.py | 加载指定训练的权重，默认补跑验证集和测试集的固定权重报告。 |
| predict.py | 回放一面墙，也可提供逐帧预测。 |
| reports.py | 生成训练曲线，使用公共的分类与事件报表。 |

温度和功率取窗由项目 code 目录内的 cnn_power_dataset.py 共用。结果默认写入 outputs/wall_dataset/cnn_tcn_temp_power/，包含总体混淆矩阵、熔断层二分类、稳定转熔断、层首发和 Excel 总表。若已有对应的划分且数据一致，可直接在 IDE 运行本目录的 train.py。
