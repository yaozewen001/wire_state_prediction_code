# ResNet34＋多尺度 TCN＋长短温度＋功率
本模型的图像时序模块使用三路 TCN。本目录包含训练、评估、回放入口及全部模型代码。

| 输入 | 默认历史 | 特征 |
|---|---|---|
| 图像 | 同一有效段的最近 20 张灰度图 | ResNet34 逐帧输出 512 维，图像时序分支输出 64 维 |
| 短温度 | 20 张图的原配对温度，最多 40 点 | 核大小 5 的因果 TCN |
| 长温度 | 同段内截至末帧的最近 3.36 秒，最多 168 点 | 核大小 13 的因果 TCN，两路温度特征合并成 64 维 |
| 功率 | 与长温度同一截止时间，按图像帧率取 84 个位置 | 设定功率换算为千瓦，小型 MLP 输出 16 维 |

拼接后的 144 维特征经过分类头，默认预测窗口末帧之后第 1 张图的稳定、顶丝、熔断状态。层号用于划分连续段和查功率，模型收到的是历史图像、温度和功率数值。

## 数据和功率表

数据根目录、类别、图温采样比例和划分统一由项目的公共 data_config.py 配置。当前 SEED=136，读取 splits/wall_dataset_seed136。训练层来自 train_sequences.csv。新增墙或修改标注后先同步数据，再在 IDE 运行公共 split_data.py。只改功率记录时，新训练直接读取更新后的功率表。

默认在数据根目录读 `power_settings.csv`。墙名与数据文件夹名一致。每面墙填写从首层生效的功率，每次变化增加一行。每条设定沿用到下一条记录。

| 列 | 填写内容 |
|---|---|
| `wall_id` | 墙文件夹全名 |
| `layer_id` | 设定生效的层号 |
| `effective_at` | 层首调功留空。层内调功填同一采集时钟下的日期时间，例如 `2026-11-09 10:15:32.420` |
| `power_setpoint_w` | 设定功率，单位 W |

功率表在启动时校验墙、层及时间。功率采样只查询该时刻已生效的设定。图像时间来自 `frame_manifest.csv`。有 `pairing.csv` 时按采样编号核对后读取完整温度时间，温度值来自 `temperature.csv`。先按标注和实际采集段确定有效历史，再以末帧时间过滤温度。有效段刚凑满短窗即可预测。长温度不足时左侧填标准化后的 0，功率左侧沿用本段首个有效时刻的设定。

长短温度共用训练统计。参与拟合的温度点按墙和原采样编号去重，再排除 799.9。799.9 对应的观测仍按训练统计标准化后入模。验证、测试和回放使用训练保存的统计量。

## 在 IDE 里运行

上传项目的完整 code/，其中包含模型目录和公共数据、批处理及报表模块。服务器已有匹配数据和 seed136 清单时可以直接训练。

| 操作 | 结果 |
|---|---|
| 打开选定模型目录的 `config.py` | 设置批量、轮次、学习率、窗口、预测提前帧数和结果路径 |
| 查看 `model.py` | 开头的模型类展示图像、长短温度和功率的完整组装与前向计算 |
| 查看 `dataset.py`、`reports.py` | 前者准备窗口和批次，后者生成指标和图表 |
| 运行 `train.py` | 新建本模型的时间戳结果目录，保存划分、功率表快照、标准化统计及权重 |
| 运行 `evaluate.py` | 按保存的输入口径评估所选权重，生成混淆矩阵、熔断层二分类、稳定转熔断和首发报告，以及 Excel 总表 |
| 运行 `predict.py` | 逐帧回放一面已配对墙，保存逐窗概率、当前功率和实际参与的温度点数 |

环境沿用服务器已安装的 PyTorch、torchvision。其余依赖见本目录的 [requirements.txt](requirements.txt)。默认使用项目中的 `weights/pretrained/resnet34-b627a593.pth` 初始化视觉骨干。

`WINDOW_SIZE` 决定图像和短温度长度，`LONG_TEMPERATURE_STEPS` 决定长温度和功率共同的回看时长。程序会检查温度 TCN 末端能否覆盖配置的历史长度。当前核大小和膨胀配置下，短路可覆盖 57 点，长路可覆盖 169 点。常用训练参数和网络结构参数都在本模型的 `config.py`。功率时间线及长短温度取样在 `dataset.py`，特征提取和融合在 `model.py`。

默认评估 `best_model.pt`，即验证损失最低的权重。设置 `EVALUATION_EPOCH = "transition_f1"` 可评估 `best_transition_f1.pt`，结果放在该次训练的 `transition_f1_evaluation` 下。转变 F1 和首发报告适用于下一帧预测，验证集存在可评估的稳定转熔断时才生成对应最佳权重。

## 接入采集程序

从对应模型包的 `predict.py` 导入 `FutureStatePredictor`。开始一面新墙时先调用 `reset(墙名)`，再用 `record_power(瓦数, 生效时间)` 登记初始设定和后续变更。图像到达时调用 `update`，传入图像、配对温度、原帧号、图像和温度采集时间、层号及当前加工是否可预测。时间可用同一时钟下的日期时间或相对秒数。历史累积满后返回三类概率。跨层、换段或遇到不可用帧时重新累计局部历史。
